Boxing Timer Web App

Files:
- index.html
- manifest.json
- service-worker.js

How to use:
1. Open index.html in a browser, or upload the folder to any static hosting.
2. On iPhone Safari, open the page and use Share > Add to Home Screen.
3. Tap Start once to unlock audio.
4. Upload your own bell/warning sounds if you want.

Notes:
- Best used with the screen kept on.
- Browser apps on iPhone can be less reliable in deep background / locked state than native apps.
- Uploaded sounds are stored in local browser storage on that device.
